# Internship Tracker

A web-based Internship Tracker built using Flask and SQLite to help users organize and track internship applications.

## Features
- Add internship applications
- Update application status
- Delete applications
- Track Applied, Interview, Rejected and Selected statuses
- Responsive UI

## Tech Stack
- Python
- Flask
- SQLite
- HTML
- CSS
- Bootstrap
- Docker
- Git

## Run Locally

git clone https://github.com/sristiii17/internship-tracker-flask.git

cd internship-tracker-flask

pip install -r requirements.txt

python app.py
